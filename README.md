# RailSync AI

## 1. Overview

RailSync AI is a railway maintenance block-planning decision-support prototype designed to help railway controllers identify maintenance work that can be coordinated within suitable operational block windows.

The system combines:

- Data fusion from representative railway maintenance and operational datasets
- Machine-learning-based maintenance prioritization
- Explainable AI using SHAP
- Cross-department joint maintenance opportunity detection
- Constraint-based block optimization using Google OR-Tools CP-SAT
- Human-in-the-loop controller approval
- Prototype handoff to the existing BDMS workflow

The central principle is:

> **AI recommends. Human decides.**

RailSync AI is a **decision-support layer**. It does not replace existing railway operational systems such as TMS, TDMS, SMMS, COA or BDMS.

---

# 2. Problem

Railway maintenance activities are generated by multiple departments and may need to compete for limited track/block windows.

Maintenance jobs may be:

- geographically close,
- required within similar time periods,
- dependent on different but compatible resources,
- generated by different maintenance departments.

Planning these jobs independently can result in fragmented maintenance blocks and inefficient use of available operational windows.

RailSync AI attempts to identify opportunities where compatible maintenance work can be coordinated and then uses constraint optimization to recommend a feasible block plan.
